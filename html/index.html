BWR 屏（驱动 3）会自动附带全白红色平面。
深睡 = 推送成功后布防,蓝牙断连且空闲达到延时才 System OFF (窗口期内可再连推下一张);图像常显、续航最长,需复位键或 wakeup 脚 (可接 NFC 检波/无线充上电信号)唤醒。不勾 = 常驻模式,适合番茄钟等周期推送应用。
面板休眠后需复位/唤醒脚才能再刷新(实验性);复位与 System OFF 需按复位键或 wakeup 脚唤醒;擦除配置恢复出厂(引脚/驱动/电源模式清零)并自动复位。
直接发送任意命令字节 + 载荷,用于对照下方命令表排查。
命令参考（固件支持的全部命令）
命令字节载荷说明
SET_PINS007 字节引脚重设屏幕引脚映射（写入配置页）；顺序为 MOSI/SCLK/CS/DC/RST/BUSY/BS
INIT01驱动 ID初始化面板并切换驱动：1=UC8176 黑白、2=V2 黑白、3=UC8276C 黑白红；写入配置页
CLEAR02—清空屏幕（全白整屏刷新）
SEND_CMD03面板命令向面板直发一条寄存器命令，配合 SEND_DATA/DISPLAY 做点亮排查
SEND_DATA04数据…向面板直发数据（跟在 SEND_CMD 后）
DISPLAY05—触发面板刷新（直写 RAM 后使用）
SLEEP06—面板进入深睡（0x07 0xA5）；之后刷新需复位唤醒，实验性
SET_CONFIG90配置结构整包写入配置页（引脚+驱动+保留字节）
SYS_RESET91—MCU 软复位，断开当前连接
SYS_SLEEP92—立即进入 System OFF；只能靠复位键或 wakeup 脚唤醒
SET_POWER93[模式][延时?s]电源模式：0=常驻（持续广播）、1=深睡（断连空闲“延时”秒后 System OFF，默认 60）
CFG_ERASE99—擦除配置页并复位，恢复出厂默认
STREAM_BEGINB0[平面号]开始一个平面，设备以 notify 回执状态与平面大小
STREAM_DATAB1PackBits 数据追加压缩像素，每包 ≤19 字节，无回执
STREAM_ENDB2[长度2][校验4][标志1]校验解码后的整平面（长度+字节和），标志位 1=刷新；校验不过不刷新
STREAM_ABORTB3—放弃当前帧，面板保持原样
GET_STATUSB5—查询状态，notify 回执：流状态/平面/已收字节/平面大小/驱动/电源模式/宽限秒数

图像路径的 Begin/Data/End 由三个内容模式内部完成，无需手工发送； 0x00–0x06 与 0x90–0x99 为原始调试命令。协议完整定义见仓库 EPD/EPD_ble.h。
