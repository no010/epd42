## 墨水屏上的番茄钟，长什么样

画面很简单，简单到只有一个比喻：**一只沙漏**。

- 上半球的沙子，是剩余的时间；
- 下半球堆起的沙子，是已经流逝的时间；
- 计时运行中，中间有一道细细的沙流落下。

整个屏幕上只有一个数字：**"剩 X / Y 分钟"**。

没有秒。这不是偷懒，是刻意为之——墨水屏刷新一次要几秒钟，显示秒本来就没意义。但我们把这个"限制"变成了设计：

**专注这件事，本来就不该按秒计算。**

番茄钟训练的是"以 25 分钟为单位沉浸做事"的节律感。盯着秒数流逝，只会让人更焦虑；而一只缓慢下漏的沙漏，给你的信号只有一个：**还在流，别抬头。**

画面底部是一排圆点，记录这一组番茄的进度：实心是完成的、带芯的是正在进行的、空心的是还没开始的；顶部是标题和最近一次刷新的时间。

一眼扫过去，不用凑近，不用点亮，它就静静地待在显示器旁边或书桌一角。

## App 本身：克制，但够用

计时跑在电脑端的命令行上位机里（Python 3.10+，开源），墨水屏只负责"显示结果"。设计上我们坚持两条原则：

**1. 屏幕永远不打扰你。**

墨水屏刷新一次要几秒，频繁整屏刷新既伤屏又耗电。所以画面默认**每 3 分钟推送一次 + 阶段切换时推送**，间隔可以自己调，甚至可以设成"只在切换专注/休息时刷一次"。

**2. 计时永远不丢。**

状态实时写在本地的 `state.json` 里：电脑重启、终端被关、中途断电，下次启动都从断点继续，还会按真实时间把中间流逝的时间补回来。

其余该有的都有：

- 默认 **25 分钟专注 + 5 分钟短休息，每 4 个番茄一次 15 分钟长休息**，时长和轮数全部可自定义；
- 交互就五个键：**空格暂停/继续、r 重置、n 跳过、s 立即推送、q 退出**；
- 不想连蓝牙？它就是一只纯粹的终端番茄钟，还能随时渲染出预览图；
- 部署极简：单文件版本约 **72KB**，复制到任何一台装了 Python 的电脑就能跑；Windows 用户双击 `.cmd`，首次自动装依赖，以后双击即用。

渲染全部在电脑端完成，设备里不存字体、不存帧缓冲，只接收打包好的位图——**这意味着你想改画面，不用动固件，改几行绘图代码就行。**

## 硬件：一只来自电商平台的"电子价签"

重点来了，也是这套方案最有趣的地方：

这块 4.2 寸墨水屏（400×300），原本只是电商平台上常见的**电子货架价签**，几十块钱。刷上我们开源的 EPD42 固件，它就变成了一块蓝牙墨水屏显示器。

- **黑白双色**和**黑白红三色**两个版本都支持；
- 固件开源，Release 里有现成的二进制，**不用改代码，刷进去就能用**；
- 支持睡眠唤醒（NFC / 无线充电器），平时近乎零功耗；
- 还自带一个**网页版上位机**，浏览器打开就能通过 Web Bluetooth 往屏幕上推图。

墨水屏的物理特性，让它天生就是"桌面时钟/番茄钟"的完美载体：

**无背光、不伤眼；画面静止时不耗电，可以常亮；不用抬手点亮，信息一直在那儿——但永远不发出任何一声提醒。**

它是显示器的反面：显示器想尽办法抢你的注意力，它只在你想看的时候，才被你看见。

## 一块屏幕，不止番茄钟

同一套固件和协议，还能跑我们的另一个上位机：**AI 订阅余额监视器**。

Kimi、DeepSeek、智谱、OpenAI……把 API 余额和用量画成一张卡片推到墨水屏上，抬头就能看到自己"还剩多少弹药"。

买一只价签，刷一次固件，**番茄钟 + AI 仪表盘，两块屏幕一块钱**（好吧，是一块屏的两副灵魂）。对爱折腾的人来说，固件和上位机全部开源，你完全可以把它改成任何你想要的样子：天气、日历、粉丝数、服务器状态……

## 它适合谁

- **工位打工人**：显示器旁放一只，进入心流前瞄一眼沙漏，比手机倒计时温和得多；
- **备考党 / 学生**：书桌上的"无游戏、无弹窗"计时器，不碰手机也能执行番茄工作法；
- **家长**：给孩子一个不带娱乐功能的专注工具，不用把手机或平板递到他手上；
- **桌面搭配爱好者**：4.2 寸、纯白底、黑墨线，放在任何桌面上都不违和；
- **开源 / hack 玩家**：从固件到绘图代码全开放，欢迎来改。

## 怎么开始

三步：

1. **买**：电商平台搜索"4.2 寸 墨水屏 价签"，或直接点文末链接（黑白双色、黑白红三色均可）；
2. **刷**：到 GitHub 仓库的 Release 下载对应固件，几分钟刷好，开箱即用；
3. **跑**：电脑上运行番茄钟上位机（或直接打开网页版上位机），把沙漏推上屏幕。
