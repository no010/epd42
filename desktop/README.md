# EPD42 番茄钟桌面版

Tauri v2 应用，Windows 下无需安装 Python。Rust 后台负责计时、阶段通知、记录保存、沙漏渲染和 BLE 推送；TypeScript 前端只负责显示状态与提交操作。

## 使用

* 墨水屏底部固定显示“今日完成 N 个番茄”。任务描述为选填项，只在桌面输入框和会话记录中保留；填写或修改任务不会触发屏幕推送。任务管理暂不进一步扩展，待用户反馈后再评估。
* 会话开始后不能改写当前任务；可以填写“下一番茄”，点击“保存”，进入下一个专注阶段时自动应用。“取消安排”保留现有任务，保存空白则安排一个未命名任务。
* 开启“自动开始下一阶段”时，自然结束和手动跳过都会继续计时；关闭时两者均停在下一阶段等待开始。
* 关窗隐藏到托盘，计时与通知继续由 Rust 后台运行。托盘菜单和 Ctrl+Alt+P 直接控制后台暂停/继续，Ctrl+Alt+S 请求推送。真正退出请使用托盘菜单。
* 设备地址可以保存；选择“自动查找”可解除绑定。推送前查询实际驱动，只有不一致才切换并回读。使用已有 BLE 命令，不需要修改固件。
* 自动推送在阶段切换和操作时同步，默认另每三分钟同步。间隔 0 表示仅在变化时推送。
* 推送期间的新请求合并为一次最新状态推送。失败最多尝试四次。关闭自动推送会取消当前重试及待推送请求；“取消推送”可单独取消本次操作，未来的周期推送仍按设置进行。已经提交到设备的刷新不能撤回。
* 状态区显示推送结果与最后成功时间。取消会中断等待/传输并尝试断开设备，断开清理最多五秒。
* Windows 通知使用 `com.epd42.pomodoro` 身份，名称为“EPD42 番茄钟”。通知名称已实机确认，测试按钮已移除。首次通知为当前用户注册应用名称和图标，无需管理员权限。

## 计时与数据

运行中的倒计时使用 `Instant` 单调时钟，系统校时不会改变剩余时长。后台检查间隔为 250ms，前端接收约每秒一次的状态；不依赖前端定时器触发结算或推送。

* 检测到后台循环超过 60 秒未执行时，暂停并保留挂起前的剩余时间，不把整段系统睡眠记录为专注时间。
* 完全退出后再启动，按已保存的墙钟截止时间恢复。若已到期，仅结算原阶段一次并等待开始下一阶段，不连续补算离线期间的番茄。
* 阶段状态、会话 ID、完成/跳过/中断记录、每日统计及设置保存在同一个 `sessions-v1.json` 中。临时文件写入并同步后原子替换；保存成功后才发布状态，避免统计和阶段状态分开写入。
* 每次操作和阶段切换保存；运行中每 15 秒保存检查点。记录保留最近 500 条，界面展示最近 20 条，每日统计独立保留。
* 首次启动从旧版 localStorage 导入计时、任务、记录、统计和设备设置；成功迁移后以 Rust 文件为准，旧数据留作备份，后续启动不会重复导入。
* Windows 数据路径为 `%LOCALAPPDATA%\com.epd42.pomodoro\sessions-v1.json`。数据解析失败时保留原文件并报错，不静默重置。
* “清空”重置计时轮次，保留历史记录、统计和任务。

## 代码结构

```text
web/src/main.ts          界面、IPC 与状态显示
web/src/timer.ts         传输类型、格式化、一次性旧数据转换
src-tauri/src/session.rs 单调时钟状态机、恢复、原子保存
src-tauri/src/runtime.rs 后台循环、命令、推送队列及取消
src-tauri/src/render.rs  预览/推送共用的沙漏与今日计数渲染
src-tauri/src/ble.rs     BLE 协议、流式发送、应答与断开清理
core/src/face.rs         沙漏布局与固定文字绘制
core/src/lib.rs          位打包、PackBits、分帧及校验
```

IPC 参数采用 Tauri 的 camelCase 约定，serde 返回结构体也统一使用 camelCase。

## 检查与构建

在 `desktop/` 执行：

```sh
cargo check --workspace --all-targets --offline
cargo test --workspace --offline
```

前端检查、测试、构建（在 `desktop/web/`）：

```sh
npm run check
npm test
node --check scripts/build.mjs
node scripts/build.mjs
```

回到 `desktop/` 后构建裸 exe：

```sh
cargo build --release --offline -p epd42-pomodoro
```

产物为 `desktop/target/release/epd42-pomodoro.exe`。构建前请从托盘退出旧版，否则 Windows 会锁定 exe。也可使用 `npm run build` 通过 Tauri CLI 生成安装包，自动执行前端构建。

测试覆盖协议编码、8 字节及扩展状态应答、沙漏几何、手动跳过、取消排队推送、单调计时、睡眠暂停、离线结算去重、原子保存失败重试、迁移和下一任务应用。

## 当前范围

* Python CLI 的状态与桌面版不互通，Python 渲染仍为独立实现。
* 设备配置向导、记录导出与更多统计仍可后续扩展。
